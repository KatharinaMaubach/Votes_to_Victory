# From Votes to Victory


Wie haben sich die Wahlergebnisse in Münster über die Jahre entwickelt? Und welchen Einfluss haben sozio-demographische Faktoren auf das Wahlverhalten und die Wahlbeteiligung? In unserem TechLabs Projekt "From Votes to Victory" haben wir die Bundestagswahlergebnisse von Münster analysiert, bereinigt und visuell in interaktiven Dashboards dargestellt.
